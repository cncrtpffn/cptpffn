# Геометрия и пропорции персонажей (стиль NickliesCat)

Эталон — моряк-рулевой: `src/scene/sailor.js`, стенд `src/debug/sailor-viewer.html`, история правок в `docs/changes/sailor-model/summary.md`.
Документ нужен, чтобы новые персонажи (3D-модели и картинки из генераторов) попадали в те же форму и пропорции.

**Единица — радиус головы R.** Геометрия моряка задана для R = 0.197 м, ниже размеры даны в R и в этих метрах.
В игре вся модель масштабирована ×1.1 (`SAILOR_SCALE`): R = 0.217 м, полная высота ≈ 1.05 м. Пропорции от этого не меняются.
Система координат персонажа: лицом к +Z, вверх +Y, начало — на сиденье (или на земле) под центром тела.

## 1. Общая схема
Персонаж собран из **4 отдельных частей**, каждая анимируется независимо:
1. **Голова** — шар с лицом, бородой (если есть) и головным убором.
2. **Тело** — одежда, без кожи, без рук и ног.
3–4. **Руки** — две сферы телесного цвета, ни с чем не соединены.

Шеи как части тела нет. Между головой и телом допускается короткий цилиндр-шея, он почти полностью скрыт головой.

| Пропорция | Значение |
|---|---|
| Полная высота (сиденье → макушка убора) | ≈ 4.8 R (0.95 м) |
| Высота тела | 2.43 R (0.478 м) |
| Ширина тела (макс.) / ширина головы | 1.14 |
| Центр головы над сиденьем | 3.3 R (0.65 м) |
| Головной убор над центром головы | ≈ 1.5 R (0.30 м) |
| Диаметр головы / полная высота | ≈ 0.41 |

## 2. Тело — «сплющенная капля»
Тело — **не тело вращения и не бочонок**. Три правила:
- **В анфас** плечи заметно уже низа. Самое широкое место («пузо») — на **середине высоты** тела, к дну тело немного сужается.
- **В профиль** грудь полого опускается к животу, спина почти прямая.
- Дно плоское, нижняя кромка скруглена.

### Глубина (спереди назад)
Глубина — доля от полуширины W на той же высоте, отдельно для переда (`K_FRONT`) и спины (`K_BACK`).
Сечение — два полуэллипса, сшитые по бокам.

|---|---|---|
| 0.00 | 0.82 | 0.95 |
| 0.12 | 0.86 | — |

Отсюда: живот выступает вперёд на 0.2 м, грудь у плеч — всего на 0.11 м. Спина везде около 0.2 м.

### Одежда
Одежда лежит **на поверхности тела накладками** (`surfacePatch`): лацканы, вырезы, вставки, кромки, карманы. Контур накладки задаётся в координатах «дуга от середины груди × высота», выдавливается на 2–18 мм и обтягивает тело. Пуговицы — сплюснутые полусферы, ставятся по нормали поверхности (`bodyPoint`).
- Лацканы — на тон светлее основной ткани, иначе не читаются.
- Вырез у горла: над воротом нижней рубашки видна кожа.
- Воротник сзади — полоса вокруг шеи.

## 3. Голова
- Шар радиуса R, без деформаций.
- **Стоит на теле, не утоплена в воротник.** Шарнир (точка, вокруг которой голова поворачивается и кивает) — у основания шеи, на 0.47 м (почти макушка тела 0.478). Центр шара на 0.18 м (0.91 R) выше шарнира. Низ головы на 0.025 м ниже макушки тела, то есть голова опирается на плечи.
- Шея: открытый цилиндр r = 0.38–0.43 R, высота 0.35 R, телесного цвета.
- **Глаза** — две чёрные точки:
  - на высоте центра головы;
  - по ±21° от направления вперёд (направление `(±0.36, 0.04, 0.93)`);
  - радиус 0.08 R, сплюснуты по нормали до 0.45 и вытянуты по вертикали ×1.15;
  - моргание — `scale.y` → 0.12.
- Рта, носа и бровей нет.

## 4. Головной убор
Общие правила для любого убора: шапки, каски, шляпы.
- **Шарнир убора — точно в центре шара головы.** Тогда наклон не отрывает убор от головы: шар симметричен.
- **Посадка по голове.** Внутренний радиус нижней кромки равен сечению головы на её высоте h: `r_in = √(R² − h²)`. Ничего не висит в воздухе и не проваливается внутрь.
- **Наклон назад** 0.17 рад (≈ 10°) к горизонту. Спереди открыт лоб, сзади кромка ниже. Смещения на затылок нет.
- Между глазами и передней кромкой убора — ≈ 0.25 R (5 см).

### Вязаная шапка моряка
| Элемент | Размер |
|---|---|
| Отворот: низ / верх над центром головы | 0.15 R / 0.81 R (0.03 / 0.16 м) |
| Отворот: внутренний радиус | 0.99 R (`√(R² − 0.03²)`) |
| Отворот: толщина валика | 0.14 R (0.028 м), снаружи ≈ 1.13 R |
| Рубчики | 28 вертикальных, глубина ≈ 0.04 R |
| Купол: радиус основания / верх над центром | 1.05 R / 1.52 R (0.30 м) |

Купол — четверть эллипса от основания до макушки. Шов развёртки уведён назад.

## 5. Руки
- Сферы радиуса 0.29 R (0.058 м), телесного цвета.
- **Поза покоя:**
  - x = ±1.62 R (±0.32 м) от оси тела;
  - y = 0.33 высоты тела (0.16 м);
  - z = +0.1 R (чуть впереди оси).
- Зазор между рукой и боком ≈ 0.2 R (4 см): руки висят рядом, но тела не касаются.
- Досягаемость для анимации — шар радиусом ≈ 2.5 R (0.5 м) от точки «плеча» на боку тела под линией плеч.

## 6. Материалы и цвета
Рендер гладкий (`MeshStandardMaterial` без `flatShading`), **без контура**, roughness 0.8–0.95.

| Материал | Цвет |
|---|---|
| Кожа | `#e8b48a` |
| Бушлат / лацканы | `#343e5a` / `#3a4565` |
| Латунь | `#a88a45` (metalness 0.5) |
| Шерсть шапки | `#d8352c` |
| Глаза | `#141414` |
| Тельняшка | синие `#2b3a78` и белые `#f2efe6` полосы, период 4.5 см |

## 7. Чек-лист для нового персонажа
1. Тело взять по таблицам раздела 2. Менять можно ±10 % по ширине (крупнее/худее), форму капли сохранять: плечи уже живота, пузо на середине высоты, грудь полого к животу.
2. Голова R = 0.197, стоит на теле на шарнире 0.47 м, глаза на высоте центра.
3. Убор: шарнир в центре головы, внутренний радиус по сечению головы, наклон ≈ 10° назад.
4. Руки — сферы 0.29 R, по бокам на трети высоты тела, с зазором.
5. Одежда — накладками по поверхности, без отдельных рукавов и ног.
6. Сверить на стенде `sailor-viewer.html` (4 ракурса) рядом с референсом.
