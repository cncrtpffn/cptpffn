# Кэтбот — парусная 3D демо-сцена

Браузерная демка в духе Sid Meier's Pirates: игрок управляет кэтботом — гафельным
одномачтовым парусником Новой Англии конца XIX века. Упор на физику: парус, руль,
шверт, крен, рифы, откренивание, волны, порывы и переворот.

## Запуск

Сборка не нужна. Three.js подгружается с CDN, поэтому нужен интернет и любой
статический сервер (ES-модули не работают с `file://`):

```
python3 -m http.server 8080
```

Открыть <http://localhost:8080>. **Space** (или кнопка ❚❚) — пауза со справкой по управлению.

## Управление

| Клавиши | Действие |
|---|---|
| ← → / A D | руль (сам возвращается в ДП) |
| ↑ ↓ / W S | грота-шкот: выбрать / потравить |
| Q / E | шверт: поднять / опустить |
| R / F | взять риф / отдать риф |
| Z / X / C | рулевой: на шаг к левому борту / на другой борт / на шаг к правому борту (4 положения: откренка и банка на каждом борту) |
| V | вид камеры (орбита / за кормой / сверху / с палубы), мышь — обзор, колесо — зум |
| Enter | поставить лодку после переворота |
| Space / H | пауза и справка (Esc — продолжить) |

Клавиши-подсказки на плашках HUD нажимаются и мышью: клик — как нажатие клавиши, зажатая кнопка мыши — как
удержание (руль, шкот, шверт).

### На телефоне

На тачскрине (или с `?touch=1` в адресе) появляется экранное управление:

| Контрол | Действие |
|---|---|
| слайдер «руль» (слева внизу) | отклонение пальца — скорость перекладки руля; отпустите — руль вернётся в ДП |
| слайдер «шкот» (справа) | вверх — выбрать, вниз — потравить |
| шверт ▲ ▼ | держать — поднять / опустить |
| риф + − | взять / отдать риф |
| экипаж ◀ ● ▶ | левый борт / центр / правый борт |
| ⛶ 🎥 ❚❚ | полный экран; вид камеры; пауза и справка |
| палец / щипок по сцене | обзор / зум |

На телефоне игра работает только в вертикальной ориентации: в горизонтальной
поверх сцены появляется просьба повернуть телефон, симуляция стоит. На Android в
полноэкранном режиме ориентация фиксируется на портрете.

Полноэкранный режим — кнопка ⛶ (на десктопе тоже). На iPhone Safari не даёт
разворачивать страницу на весь экран, поэтому кнопки там нет; играть без интерфейса
браузера можно, добавив сайт на экран «Домой» (Поделиться → На экран «Домой»):
манифест `manifest.webmanifest` открывает его как полноэкранное приложение.

Компас в приборах показывает ветер, гик и лодку на одной картинке. Лодка стоит носом
вверх, под неподвижной риской сверху крутится картушка с курсом. Стрелки ветра
проходят через весь круг и показывают, куда дует ветер: толстая оранжевая —
вымпельный ветер, тонкая синяя — истинный. Коричневая линия от мачты — гик,
пунктир — предел шкота: гик, упёршийся в пунктир, значит, что шкот держит парус.
Чёрная чёрточка на транце — перо руля.
Красный кружок на гике — центр парусности (ЦП), синий ромб на диаметральной
плоскости — центр бокового сопротивления (ЦБС). Если лодка без руля пошла бы к
ветру или от ветра, у носа появляется дуговая стрелка: красная — лодка приводится,
бирюзовая — уваливается. На стоянке ЦБС и стрелка скрыты. Метки расшифрованы в легенде
внизу панели. N на картушке синяя, S красная. В свёрнутой панели — упрощённый
мини-компас: картушка через 45°, силуэт лодки и вымпельный ветер.

Пока игра загружается, на экране тот же компас: лодка за 25 секунд делает полный
круг, гик перекладывается так же, как в игре. Ниже показан текущий этап загрузки,
полоса прогресса и время уже готовых этапов. Анимация компаса сделана на CSS
(`src/ui/loading-anim.css`) и не замирает на тяжёлых этапах. Кадры анимации заранее
считает `src/debug/gen-loading-anim.mjs` по физике паруса, после правок паруса или
поляры их надо пересчитать (команда — в шапке скрипта).

Все панели (приборы, органы управления, подсказка, погода) сворачиваются кнопкой в
углу; на маленьких экранах они свёрнуты по умолчанию, выбор запоминается.
На таче приборы и органы управления собраны в одну плашку у верхнего края. В ней нет крена, дрейфа,
углов ветра и бара руля. Свёрнутая плашка показывает мини-компас, скорость, курс и статус паруса.

Панель справа: сила и направление ветра, порывы и заходы, волнение, пресеты
погоды, время суток.

Учебник для новичка — [`manual.html`](manual.html): части лодки, ветер, курсы, повороты, глоссарий.

## Стартовые настройки (start.json)

`start.json` в корне задаёт, с чего начинается игра. Все значения потом можно менять в игре. Панель — это
«Погода и сцена» (справа вверху), HUD — плашка с компасом.

| Настройка | Что задаёт | Значения | Где видно |
|---|---|---|---|
| `timeOfDay` | время суток | 0..1: 0 — рассвет (солнце на 8° под горизонтом), 0.5 — полдень, 1 — закат | панель → «Сцена» → «Время суток»; `?tod=` |
| `weather.preset` | имя пресета ветра в панели. Только подпись: ветер берётся из `weather.wind` | `Штиль`, `Лёгкий бриз`, `Умеренный`, `Свежий ветер`, `Крепкий ветер`, `Шторм` | панель → «Ветер» → «Пресет» |
| `weather.clouds` | облачность | `Ясно`, `Кучевые`, `Перистые`, `Пасмурно`, `Холодный фронт`, `Гроза` (`CLOUD_TYPES` в `src/scene/clouds.js`) | панель → «Сцена» → «Облачность»; `?clouds=` |
| `weather.wind.speed` | базовая скорость ветра | м/с, в панели 0–22 | панель → «Ветер» → «Скорость» и «Бофорт»; HUD → «Истинный»; `?wind=` |
| `weather.wind.dirDeg` | откуда дует ветер | 0–360°, 0 — с севера, 90 — с востока | панель → «Ветер» → «Откуда»; на компасе HUD синяя стрелка; `?winddir=` |
| `weather.wind.gusts` | порывы и заходы | `true` / `false` | панель → «Ветер» → «Порывы» |
| `weather.wind.gustStrength` | сила порывов, доля скорости | 0–0.6 | панель → «Ветер» → «Сила порывов» |
| `weather.wind.shiftDeg` | амплитуда заходов ветра | 0–40° | панель → «Ветер» → «Заходы, ±°» |
| `weather.sea.auto` | волнение от ветра | `true` — от ветра, `false` — берётся `weather.sea.state` | панель → «Море» → «Волнение от ветра» |
| `weather.sea.state` | ручное волнение | 0..1, 1 — значимая высота `SEA.maxHeight` (2.2 м) | панель → «Море» → «Волнение вручную» |
| `boat.x`, `boat.z` | стартовая точка лодки | м, координаты мира | `src/debug/map-viewer.html`: метка «старт» и сетка координат; `?log` печатает `boat=(x,y,z)`; `?pos=x,z` |
| `boat.headingDeg` | стартовый курс | 0–360°, 0 — на север, 90 — на восток | HUD → «Курс» и компас; жёлтая стрелка в map-viewer; `?pos=x,z,курс` |
| `boat.reefs` | рифы | 0 — полный парус, 1 и 2 — рифы, 3 — парус спущен | HUD → «Рифы»; клавиши R/F; `?reefs=` |
| `boat.board` | шверт | 0..1: 0 — поднят, 1 — опущен | HUD → «Шверт»; клавиши Q/E; `?board=` |
| `camera.mode` | вид камеры | `orbit` (орбита), `chase` (за кормой), `top` (сверху), `deck` (с палубы) | подсказка внизу: «Камера: …»; клавиша V; `?cam=` |
| `camera.angleDeg` | угол камеры относительно лодки | от носа по часовой: 0 — спереди, 90 — с правого борта, 180 — за кормой; в `deck` — куда смотрит рулевой | мышь / палец; `?camaz=` (мировой азимут) |
| `camera.distance` | зум | 5–70 м | колесо / щипок; `?camdist=` |

Особенности:
- На карте со своим стартом (`?map=archipelago`) положение и курс лодки берутся из карты. `?pos=` главнее обоих.
- URL-параметры главнее `start.json` (таблица всех параметров — на `tools.html`).
- Блок `camera` и его поля необязательные.

## Инструменты

Все стенды, параметры игры, консольные хелперы и команды собраны на странице [`tools.html`](tools.html)
(`http://localhost:8000/tools.html` под тем же сервером). URL-параметры игры заведены в реестре
`src/params.js`: новый параметр добавляется туда (имя, тип, описание, пример) — по реестру его разбирает
`main.js` и он сам появляется в таблице на странице. Новый стенд или параметр стенда — допиши карточку в `tools.html`.

## Отладка физики

Физика (`src/physics/*`) не зависит от Three.js. Поляра (установившийся режим на
разных курсах под автопилотом) считается без браузера через JavaScriptCore:

```
/System/Library/Frameworks/JavaScriptCore.framework/Versions/Current/Helpers/jsc -m src/debug/run-polar.mjs
```

В браузере то же доступно из консоли: `polar(10)`, `runCase({ tws: 12, twa: 60, reefs: 1 })`.

Параметры URL для воспроизводимых сцен: `?t=30&twa=60&wind=9&cam=chase&reefs=1&board=0&tod=0.9` (`pos=x,z,курс°` — поставить лодку в точку)
(`t` — промотать столько секунд под автопилотом, `auto` — оставить автопилот включённым, `log` — лог в консоль).

## Производительность

`?perf=1` (или панель «Погода и сцена» → «Производительность» → «Счётчик кадра») показывает вверху медианы
GPU- и CPU-времени кадра, draw call'ы и треугольники за все проходы, плотность пикселей и размер буфера.
Разрешение по умолчанию подстраивается само: потолок DPR — 2 на десктопе и 1.5 на таче, если GPU-время кадра
выше бюджета (11 мс), DPR снижается ступенями по 0.25. `?dpr=1.5` фиксирует плотность вручную.
Аудит и замеры до/после: [docs/changes/perf-audit](docs/changes/perf-audit/summary.md).

```
index.html, style.css      — разметка HUD, стили

src/physics/wind.js        — истинный/вымпельный ветер, порывы
src/physics/waves.js       — волны Герстнера (CPU-часть), системы волн и зыбь
src/physics/sail.js        — грот: шкот, гик, рифы, заполаскивание, фордевинд, силы
src/physics/boat.js        — корпус, шверт, руль, остойчивость, заливание, переворот
src/scene/*                — вода (шейдер), модель лодки, окружение, камера
src/scene/merge-static.js  — слияние неподвижных деталей в один меш на материал
src/perf.js                — замеры кадра, счётчик ?perf=1, авто-разрешение
src/ui/*                   — HUD и панель погоды
src/debug/polar.js         — автопилот и прогон поляры
src/debug/map-viewer.html  — стенд карты мира: острова, глубины, берег (docs/changes/world-map)
src/debug/props-viewer.html — стенд библиотеки объектов: флора и постройки (docs/changes/structures-library)
src/scene/structures/*     — библиотека построек: реестр, кит деталей и палитры стилей, модели
```
