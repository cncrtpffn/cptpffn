# Кэтбот — парусная 3D демо-сцена

Браузерная демка в духе Sid Meier's Pirates: игрок управляет кэтботом — гафельным
одномачтовым парусником Новой Англии конца XIX века. Упор на физику: парус, руль,
шверт, крен, рифы, откренивание, волны, порывы и переворот.

## Запуск

Сборка не нужна. Three.js подгружается с CDN, поэтому нужен интернет и любой
статический сервер (ES-модули не работают с `file://`):

```
python3 -m http.server 8080
```

Открыть <http://localhost:8080>. **Space** (или кнопка ❚❚) — пауза со справкой по управлению.

## Управление

| Клавиши | Действие |
|---|---|
| ← → / A D | руль (сам возвращается в ДП) |
| ↑ ↓ / W S | грота-шкот: выбрать / потравить |
| Q / E | шверт: поднять / опустить |
| R / F | взять риф / отдать риф |
| Z / X / C | экипаж на левый борт / в центр / на правый борт |
| V | вид камеры (орбита / за кормой / сверху / с палубы), мышь — обзор, колесо — зум |
| Enter | поставить лодку после переворота |
| Space / H | пауза и справка (Esc — продолжить) |

### На телефоне

На тачскрине (или с `?touch=1` в адресе) появляется экранное управление:

| Контрол | Действие |
|---|---|
| слайдер «руль» (слева внизу) | отклонение пальца — скорость перекладки руля; отпустите — руль вернётся в ДП |
| слайдер «шкот» (справа) | вверх — выбрать, вниз — потравить |
| шверт ▲ ▼ | держать — поднять / опустить |
| риф + − | взять / отдать риф |
| экипаж ◀ ● ▶ | левый борт / центр / правый борт |
| 🎥 ❚❚ | вид камеры; пауза и справка |
| палец / щипок по сцене | обзор / зум |

Все панели (приборы, органы управления, подсказка, погода) сворачиваются кнопкой в
углу; на маленьких экранах они свёрнуты по умолчанию, выбор запоминается.

Панель справа: сила и направление ветра, порывы и заходы, волнение, пресеты
погоды, время суток.

## Отладка физики

Физика (`src/physics/*`) не зависит от Three.js. Поляра (установившийся режим на
разных курсах под автопилотом) считается без браузера через JavaScriptCore:

```
/System/Library/Frameworks/JavaScriptCore.framework/Versions/Current/Helpers/jsc -m src/debug/run-polar.mjs
```

В браузере то же доступно из консоли: `polar(10)`, `runCase({ tws: 12, twa: 60, reefs: 1 })`.

Параметры URL для воспроизводимых сцен: `?t=30&twa=60&wind=9&cam=chase&reefs=1&board=0&tod=0.9`
(`t` — промотать столько секунд под автопилотом, `auto` — оставить автопилот включённым, `log` — лог в консоль).

## Структура

```
index.html, style.css      — разметка HUD, стили
src/config.js              — все параметры лодки и среды
src/physics/wind.js        — истинный/вымпельный ветер, порывы
src/physics/waves.js       — волны Герстнера (CPU-часть)
src/physics/sail.js        — грот: шкот, гик, рифы, заполаскивание, фордевинд, силы
src/physics/boat.js        — корпус, шверт, руль, остойчивость, заливание, переворот
src/scene/*                — вода (шейдер), модель лодки, окружение, камера
src/ui/*                   — HUD и панель погоды
src/debug/polar.js         — автопилот и прогон поляры
```
