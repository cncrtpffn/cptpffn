# Гладкий рельеф — состояние сессии (2026-11-23)

Ветка `flat_water`, последний коммит `f08876e`. Изменения задачи **не закоммичены**, ждут ОК пользователя.

## Что просил пользователь
1. Острова угловатые, видны грани — сделать затенение суши гладким, как у моря.
2. Деревья и постройки **не трогать** (остаются flatShading). Кромки клифов — **резкие**.

## Что сделано (оба шага готовы)
- `src/scene/terrain/terrain-mesh.js` — у `buildTerrain` опции `smooth` и `cliff = [0.32, 0.5]`:
  - материал `smoothMaterial()` — `MeshStandardMaterial` без flatShading и с `onBeforeCompile`: после
    `normal_fragment_begin` нормаль смешивается с нормалью грани по крутизне (1 − cos ≈47°…60°);
  - нормали вершин по полю высот (центральные разности `hf.sample` на шаге `step` = 4 м во всех чанках) — без швов
    на стыках чанков; юбке — нормаль вершины края.
- `src/scene/terrain/world.js` — `smooth: !!map.smoothTerrain`.
- `src/maps/demo.js` — `smoothTerrain: true`. У «Архипелага» флага нет, он не изменился.
- Документация: `plan.md`, `summary.md`, `img/` (before/after, after-cliff, step2-cliff, step2-slope).
