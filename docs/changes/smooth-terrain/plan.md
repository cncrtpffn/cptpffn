# Гладкое затенение суши

Задача: острова выглядят угловато — видны грани рельефа. Сделать затенение суши гладким, как у моря.

План:
1. В `buildTerrain` (src/scene/terrain/terrain-mesh.js) — опция `smooth`: материал без `flatShading`.
2. Нормали брать не из `computeVertexNormals` (на краю чанка в них попадают грани юбки, и соседние чанки
   разного шага дают разные нормали → швы), а по полю высот: центральные разности `hf.sample` на шаге `step`.
   Вершинам юбки — нормаль их вершины края.
3. Включать флагом карты `smoothTerrain: true` — только демо; «Архипелаг» не меняется.
