# Туман и LOD

## 1. Галка «Туман» — сделано
- Где: панель «Погода и сцена» → «Сцена», после «Облачности».
- По умолчанию туман включён, выбор не запоминается (как остальные галки панели).
- Дымку облаков (`clouds.js`, uFogNear/uFogFar) галка не трогает.
- `environment.js`: туман в локальной `fog`; `applyLighting` пишет цвет и дальность в неё всегда;
  `env.fogEnabled` вешает `fog` на сцену или снимает (`scene.fog = null`).
- `main.js`: деградация неба берёт фон из `env.fog.color` — `scene.fog` может быть `null`.

## 2. Туман дальше — сделано
Без тумана сцена выглядит неплохо; туман отодвинут:
- ясно (overcast 0): было 140 → 1100 м, стало ×4 — 560 → 4400 м;
- «Пасмурно» (overcast 0.85): было 89 → 803 м, стало ×2 — 178 → 1605 м;
- между ними линейно по overcast / 0.85.

## 3. Цена суши в кадре — сделано
Сколько стоят полигоны островов. Стенд `?sea=1` — суша, постройки и растительность не рисуются
(прибой, мелководье и брызги о скалы выключены, физика и буи остаются). Галки «Рельеф / Постройки /
Растительность» в «Производительности» — для A/B внутри одной сборки. Замеры — в summary.md.

## Дальше (открыто)
Туман больше не прячет границы LOD растительности (`vegetation.js`): трава пропадает на 160 м,
кусты/маквис/вереск — на 520 м, камни — на 600 м, деревья упрощаются на 260 м.
Посмотреть в движении вдоль острова, при скачках — отодвинуть границы или сделать плавное появление.
