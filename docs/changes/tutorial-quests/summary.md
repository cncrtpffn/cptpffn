# Обучающие квесты — итоги

План: [plan.md](plan.md). Ветка `tutorial-quests`.

## Шаг 1. Покомпонентный ассистент (2026-11-26)

### Что сделано
- **`src/physics/assist.js`:** `a.channels = { sheet, board, crew, reef }` (по умолчанию всё `true`)
  и `a.setChannels(mask)`; каналы, которых нет в маске, считаются `true`. Если канал выключен, `controls()`
  берёт ввод игрока из `base`: `sheet`/`sheetAngle`, `board`, `crewPos` (0 — рулевой сидит, где сидел).
  Рифы в этом случае не трогает. При ручном шкоте телеграф не действует (`request` ничего не делает),
  `limited`, `locked` и `hint` сброшены.
- **`src/main.js`:**
  - `auto(ch)` — канал на ассистенте (ассистент включён и канал в маске);
  - события `reef` и `crew` блокируются по каналам; ↑/↓ работают как телеграф только при `auto('sheet')`;
  - `syncAssistUi()` ставит `body.assist` и `body.auto-<канал>`;
  - `setAssistChannels(mask)` выставлен в `window.__sim` (им будут пользоваться уроки).
  - Кнопка `T` и `localStorage` по-прежнему включают всё сразу.
- **HUD и тач:**
  - строка телеграфа видна только при `auto-sheet`;
  - клавиши прячутся только у рядов на авто (у ряда шверта появился id `ctl-board`);
  - тач-секции шверта (`#t-sec-board`), рифов и экипажа прячутся по отдельности. Блок кнопок
    исчезает целиком, только когда все три на авто;
  - слайдер «ход»/«шкот» и его блокировка зависят от `channels.sheet`;
  - подсказки советчика (`.ctl.hint`, мигание на таче) показываются для каналов игрока
    и при включённом ассистенте.
- **`src/debug/polar.js`:** `runCase({ assist: true, channels })`. Каналы «игрока» ведёт формула
  `trim.js`: шкот `sheetTarget`, рулевой на наветренной банке.

### Проверки
- `jsc -m src/debug/run-assist.mjs`: вывод до и после изменений совпадает. Новая таблица: шкот у «игрока»
  (та же формула), остальное ведёт ассистент. Скорость совпадает с полным ассистентом (7 и 11 м/с, 45/90/135°).
- Chrome DevTools, тач 390×844, `?touch=1&assist=1`:
  - полный ассистент: все тач-кнопки скрыты, слайдер «ход»;
  - `setAssistChannels({ sheet: false, crew: false })`: видна секция экипажа, слайдер «шкот»; тяга слайдера
    выбирает шкот (−22° за 0.8 с).
- Десктоп 1440×900: при полном ассистенте у рядов нет клавиш, строка «Ход» видна.
  С `{ reef: false }` у рифов появились клавиши, и `R` берёт риф. После возврата полной маски `R` игнорируется.
  Ошибок в консоли нет.
