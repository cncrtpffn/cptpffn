# 11 — Мануал по управлению кэтботом (`manual.html`)

## Context
Справка на паузе (`index.html:94-134`) — короткая шпаргалка без схем. Новичку нужен отдельный учебник:
части лодки, ветер, курсы, почему лодка идёт против ветра, руль и шверт, баланс, крен и рифы, повороты,
безопасность, глоссарий. В каждом разделе есть блок «В игре».
Ответы пользователя (из `docs/backlog/11-sailing-manual.md`): отдельная страница, открывается из паузы в новой
вкладке; пока только русский, но потом будут английский и португальский; иллюстрации только SVG; только кэтбот,
без других типов вооружения; подсказок в HUD не делаем; опираемся на открытые источники.

## Решения
- **`manual.html` в корне**, стили инлайн, как в `tools.html`: те же токены (`--ink`, `--card`, `--accent`, `--true`),
  Nunito, карточки. Добавляю **тёмную тему** (`prefers-color-scheme` + токены для SVG: `--sea`, `--wind`, `--force`,
  `--hull`), вёрстка держит ширину 390 px. Слева оглавление (sticky на десктопе, на телефоне сворачивается в `<details>`).
- **Подготовка к переводу:** прозу держу в HTML. Перевод потом — это копия `manual.en.html` / `manual.pt.html`
  (длинный текст проще переводить целиком, а не по ключам). Подписи SVG пишу `<text>` прямо в странице, они
  переводятся вместе с ней. Глоссарий лежит в данных с полями по языкам: сейчас только `ru`, структура `{ ru: {...} }`,
  чтобы потом дописать `en`/`pt`.
- **`src/ui/glossary.js`** — без DOM: `export const GLOSSARY = [{ id, ru: { term, alt?, def } , see?: [ids] }]`.
  Страница строит из него раздел «Глоссарий» с якорями `#g-<id>`. В тексте термины размечены
  `<a class="term" href="#g-shvert">`; маленький скрипт проверяет, что у каждой ссылки есть термин, и пишет ошибку
  в консоль. Отдельно проверяю это в jsc.
- **Цифры только из нашей физики**: значения из `src/config.js` и прогонов `run-polar.mjs` (jsc). Таблицу цифр,
  которые использую, кладу в `docs/changes/sailing-manual/summary.md`.
  Уже известно: длина 6.0 м, ширина 2.8 м, парус 21.5 м², рифы 70 % и 45 % площади, гик от 12° до 88°,
  парус полощет при угле атаки < 6°, перо шверта срывается при 14°, руль кладётся до 35°, вода в кокпите с крена
  48°. По полярам при 7 м/с: лучший ход к ветру (VMG ≈ 3.8) на 35° TWA, скорость 4.9–5.1 (единицы `polar.js` сверю — м/с или узлы),
  самый быстрый курс 75–90°. При 13 м/с без рифов на 45–60° лодка переворачивается — хороший пример для раздела
  о рифах. Мёртвый угол уточню отдельным прогоном `polar` на TWA 20/25°.

## Разделы страницы
1. Лодка: части кэтбота — SVG вид сбоку и сверху: мачта в носу, гафель, гик, грот, шкот, шверт и швертовый колодец,
   руль «амбарная дверь», румпель, кокпит, банки, борта, нос, корма, ДП.
2. Ветер: истинный и вымпельный — SVG векторный треугольник (истинный + встречный от хода = вымпельный).
   Что показывают флюгер и колдунчики в игре.
3. Курсы к ветру — SVG роза курсов: левентик / мёртвый угол, бейдевинд, галфвинд, бакштаг, фордевинд; галсы.
   SVG поляра скорости при 7 м/с (данные из прогона).
4. Почему лодка идёт против ветра — SVG сил: парус как крыло (подъёмная сила ⟂ вымпельному ветру),
   разложение на тягу и дрейф, шверт гасит дрейф; угол дрейфа. Лавировка.
5. Шкот и угол атаки — полощет / тянет / перебран (статусы `luff/ok/stall` = подписи HUD из `src/ui/hud.js:5-10`).
6. Руль и шверт — как руль поворачивает корму; когда поднимать шверт (по ветру, мелководье).
7. Баланс ЦП/ЦБС — SVG: почему кэтбот приводится, особенно при крене.
8. Крен, откренка, рифы — SVG: момент крена и восстанавливающий момент экипажа; рифы и спуск паруса.
9. Повороты оверштаг и фордевинд — SVG пошагово (3–4 положения лодки на одной схеме); удар гика.
10. Безопасность: заливание и переворот, `Enter` — поставить лодку.
11. Глоссарий (из `glossary.js`).
Во всех разделах есть карточка «В игре»: клавиши и тач (как в справке на паузе) и на что смотреть в HUD.

## Шаги (после каждого — скриншоты 1280 и 390, светлая и тёмная тема, жду ОК)
1. **Каркас:** `manual.html` (стили, тема, оглавление, пустые разделы), `src/ui/glossary.js` с первыми терминами,
   рендер глоссария и проверка ссылок. Ссылки: в справке на паузе (`index.html`, рядом с «Как ходить под парусом»,
   `target="_blank"`), карточка в `tools.html`, строка в README. Папка `docs/changes/sailing-manual/` с `plan.md` и `summary.md`.
2. **Тексты разделов 1–10** + блоки «В игре» + полный глоссарий (~50 терминов). Терминологию сверяю по открытым
   источникам и ссылки на них кладу в summary.
3. **SVG-схемы** (~9 штук): части лодки, треугольник ветров, роза курсов, поляра, силы на парусе и шверте, ЦП/ЦБС,
   крен и откренка, оверштаг, фордевинд. Цвета берутся из CSS-токенов, поэтому работают в обеих темах.
4. **Сверка и финал:** все цифры против `run-polar.mjs`/`config.js`, проверка ссылок глоссария, финальный summary,
   отметка в `docs/backlog/11-sailing-manual.md`.

Интерактивные схемы (ползунок курса) не делаем — пользователь выбрал «только SVG».

## Проверка
- Сервер `python3 -m http.server` из корня (вне песочницы), headless Chrome: скриншоты 1280 и 390 px, светлая и тёмная
  тема → `docs/changes/sailing-manual/img/`.
- В консоли нет ошибок «нет термина»; jsc-скрипт проверяет, что у каждого `href="#g-…"` в `manual.html` есть id в `GLOSSARY`.
- Цифры на схемах совпадают с выводом `jsc -m src/debug/run-polar.mjs`.
- Ссылка из паузы открывает мануал в новой вкладке, игра остаётся на паузе.
