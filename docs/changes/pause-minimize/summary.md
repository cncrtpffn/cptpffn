# Свернуть диалог паузы — итог

- `index.html`: кнопка `#btn-help-min` в карточке `#help`, плашка `#paused-chip` (развернуть / продолжить) в `#hud`.
- `src/ui/hud.js`: `showHelp(v, min)` — при `min` прячет диалог, показывает плашку, ставит `#hud.paused-min`.
- `src/main.js`: флаг `helpMin`; `setPaused(v, min)`. Space и ✕/▶ — продолжить; H в свёрнутом виде разворачивает справку.
- `style.css`: плашка в позиции `#warnings` (в т.ч. тач/узкий портрет), предупреждения в свёрнутой паузе скрыты; «–» левее ✕.

Проверено в Chrome: пауза → свернуть → развернуть → H → ▶, состояния переключаются верно.
