# HUD × обучение: отметки оптимума и мигание контролов

## Контекст
Новичок видит в HUD, где сейчас шкот, шверт, экипаж и рифы, но не видит, где они должны быть. Задача:
1. На индикаторах лодки отметить оптимальное положение.
2. Мигать контролом, который нужно тронуть, когда парус перегружен:
   - **экипаж** — если крен можно убрать откренкой;
   - **шкот** — если откренки уже не хватает и надо травить;
   - **рифы** — если ветра слишком много для текущей площади. Считаем по бейдевинду, в приоритете
     безопасность.

Сейчас оптимальные значения зашиты внутри `src/physics/assist.js`: `ALPHA`, `BOARD_RUN`/`RUN_TWA`,
`REEF_AT` (11/14 м/с), выбор борта. Наружу они не выходят. Откренку (±2) ассистент не использует
(так решили в эпике 12).

## Источник правды (рекомендация)
Новый чистый модуль **`src/physics/trim.js`**, без three и DOM, тестируется в jsc. Одна функция
`trimAdvice(boat, wind, state)` возвращает цели и флаги. Её используют **и ассистент, и HUD**: ассистент
превращает цели в оси, HUD рисует отметки и мигает. Так подсказки и поведение авто-матроса не разойдутся.

```
{ sheet,            // цель угла гика: |awa| − 24°, clamp [sheetMin, sheetMax] (полный ход ассистента)
  board,            // 1 до |twa| 110°, полнее 0.3
  crewPos,          // наветренный борт: ±1 банка, ±2 откренка, если при банке крен выше HEEL_OK
  reef,             // рекомендуемая ступень 0..2 по таблице бейдевинда
  need: { crew, sheet, reef } }  // что мигать
```

- **Рифы по бейдевинду.** Расчёт идёт из той же физики:
  `sailCoeffs` (`sail.js`), `reefArea`/`reefCeHeight`, `gz()` и момент экипажа (`boat.js:265-268`).
  Офлайн-скрипт `src/debug/run-reef-table.mjs` (jsc) прогоняет `runCase` на twa 45°: оптимальный шкот,
  откренка, рифы 0/1/2. Для каждой ступени находит наибольший TWS, при котором средний крен ≤ `HEEL_SAFE`
  (≈20°) и максимальный ≤ 30° в порывах. Получается `BOAT.reefMaxTws = [a, b]` в `config.js`, рядом
  комментарий, каким скриптом пересчитывать. Решение принимается по ветру с порывом (`baseSpeed·(1+gust)`),
  сглаженному за ~8 с: так риф подсказывается заранее, а не уже в порыве. В рантайме ничего тяжёлого нет.
- **Ассистент в этой задаче поведения не меняет** (решение пользователя). Позже у него появится настройка
  «скорость или безопасность». Готовим под неё:
  - в `config.js` два профиля порогов рифов: `reefTws = { safe: [...] /* из run-reef-table */,
    fast: [[11,10],[14,13]] /* нынешний REEF_AT */ }`;
  - ассистент читает `fast`, его поведение побайтно прежнее;
  - HUD подсказывает по `safe`;
  - константы целей шкота, шверта и борта (`ALPHA`, `RUN_TWA`, `BOARD_RUN`, `CREW_BOOM_TWA`, `HEEL_EASE`)
    переезжают в `trim.js`, `assist.js` их импортирует. Это чистый рефакторинг, проверяется тем, что
    `run-assist` выдаёт тот же вывод.
- **Мигание** (только в ручном режиме, при ассистенте выключено). Крен считаем с упреждением, как
  в ассистенте: `φ + 0.3·φ̇`, сглаживание ~0.5 с, гистерезис ~2 с, чтобы мигание не дёргалось на волне:
  - крен > `HEEL_OK` (≈18°) и рулевой не на наветренной откренке → `need.crew`;
  - крен > `HEEL_EASE` (24°, из ассистента), а откренка уже стоит или не помогает → `need.sheet`;
  - ветер выше `reefMaxTws[reefTarget]` → `need.reef`, независимо от курса.

## UI
- **Отметки** — новый элемент `.opt` (тонкая вертикальная риска, цвет `--true`) поверх баров:
  - `#bar-sheet` — по цели шкота;
  - `#bar-board`;
  - `.bar.crew` — по цели экипажа;
  - рифы — рекомендуемый чип с пунктирной рамкой `.chip.opt`;
  - руль без отметки;
  - тач: горизонтальная риска на индикаторе `#t-sheet .t-ind`.

  Пишем через `css()`/`changed()` из `hud.js`, округление до 1 %, чтобы DOM не менялся каждый кадр.
- **Мигание** — общий keyframes, вынесенный из `assist-pulse` (`style.css:277`), например `hint-pulse`
  (фон ↔ `--true`), с тем же `prefers-reduced-motion`. Класс `.hint` ставится:
  - на десктопе — на ряд `.ctl` (шкот / экипаж / рифы);
  - на таче — на `#t-sheet .t-track`, на `.t-sec` экипажа и на `.t-sec` рифов (`touch.js`).
- `Hud.update({ …, advice })`, `touch.update(boat, assist, advice)`. `advice` считается в `main.js` один раз
  за кадр.

- `jsc -m src/debug/run-reef-table.mjs` → таблица порогов.
- `jsc -m src/debug/run-assist.mjs` и `run-polar.mjs`: вывод побайтно совпадает с текущим (ассистент
  не изменился).
- Chrome DevTools, десктоп и тач 390×844 (`?touch=1`), без ассистента:
  - `?t=20&twa=50&wind=7`: отметки на месте, ничего не мигает;
  - `wind=11`, рулевой на банке → мигает экипаж; после откренки → гаснет;
  - `wind=14`, откренка → мигают шкот и рифы;
  - на фордевинде при 14 м/с рифы всё равно мигают (расчёт по бейдевинду);
  - с ассистентом мигания нет;
  - нет ошибок в консоли, записи в DOM за кадр не выросли (MutationObserver, как в шаге 1 HUD).
- Скриншоты в `docs/changes/trim-hints/img/`. Коммит только после ОК.
