**Разделение карт.** «Архипелаг» в эксперименте не трогаем: он строится замороженным планом шага 3а —

**Правила (все выполняются на демо, `tests/plan-test.mjs` — «проверки пройдены»):**
1. Периметр каждой зоны — кольцевой переулок `ring` (в посёлке) или полевая дорога `track` (край окраин и полей);
   дыры в зонах (кручи) не обводятся, переулки идут через них. Покрытие границ 94–100 %.
2. T-перекрёстки: переулки полосами от продольной улицы (или кольца) до первой встречной улицы, старты полос со сдвигом.
3. Косые углы: скос трассы 18–35° к нормали улицы, концы под прямым углом сдвигаются вдоль улицы; прямых ≤ 20 %.
4. Уклон проезжих ≤ 15 % (окно 6 м): подрезка рельефа `gradeAlong` (с «замком» полотна), серпантин `ramp`
   (локальный A* 4 м, ходы конём), остаток — лестница; тропы ≤ 25 %, круче — лестница.
5. Между посёлками одного массива суши — основная дорога + запасная связь другим коридором (полевая, иначе тропа):
   на Большом — по северо-западному гребню.
6. К названным местам (пляжи, бухты, области биомов) — тропа или полевая дорога от ближайшего посёлка, если ближе 30 м
   ещё нет улицы или дороги.

Порядок `planTown`: граница → продольные → площадь и церковь («блоки») → зоны → периметры → переулки → косые концы →
уклоны → прочие резервы → причалы. Перекрёстки — `p.junctions`; макс. срез — `p.cut`.
Помощники `geom.js`: `makeRouter` (опции `maxSlope`, `steep`, `dirs16`, `ok`, `extra`), `gradeAlong` (`dry`, `lock`),
`maxGrade`; исправлен `simplify` для замкнутых контуров (раньше схлопывал их — пропадали контуры границ).
Стенд: цвета `ring/track/ramp/path`, кружки перекрёстков (T / косой X / прямой), дороги вне посёлков по участкам, легенда.
Скриншоты: `img/12-net-porto.jpeg`, `img/13-roads-bolshoy.jpeg`.

**Известное:** в Порто-Сирене много коротких лестниц (кольца на склоне рвутся), в Сосновке нет проезда в одной из полос,
у Оливето нет площади; план демо 248 мс (роутер дорог 4 м). Мысы и вершины без названий в карте — путей к ним нет

## Следующее: шаг 3б — постройки по плану
- `buildSettlements(hf, bio, map, plan)` становится только строителем:
  - ленты улиц и дорог из `plan.sites[].streets` и `plan.roads`;
  - на `stairs` — `stairs-slope`, на террасах (`terrace`) — `retaining-wall`;
  - площадь и общественные здания — в `plaza` / `reserves`;
  - причалы — по `berths` (`kind`, `x`, `z`, `nx`, `nz`, `rot`);
  - дома вдоль улиц (`fillStreet` / `alongStreet`), тип дома по `plan.zone` (core / residential / waterfront / outskirts / fields).
- Удалить сеточную раскладку в `town()` / `village()` и оси `seaward`.
- Рыбацкий посёлок (`fishing`) и `landing` сохраняют свой набор построек.
- Растительность должна обходить новые постройки (через `settle.occ`, как сейчас).
- Проверка:
  - демо — на стенде и в игре;
  - «Архипелаг» — число построек и время против `archipelago-map/summary.md`;
  - бенч кадра по правилам [perf-measurement].
