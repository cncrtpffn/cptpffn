## Шаг 3а — план поселений (данные + слой `plan`, без 3D)

Новый шаг пайплайна: heights → biomes → **plan** (`settlement-plan.js`) → `markSettle` → terrain → settlements → vegetation. Помощники геометрии вынесены в `geom.js` (изолинии, RDP, трассировка по градиенту, EDT, A*).

### Как строится улица
- **Граница** — заливка от центра по пригодным клеткам до площади π r² k. Если на крутом месте набралось меньше 60 %, допуск уклона растёт ступенями до 0.5.
- **Продольные улицы** — изолинии поля:
  - на ровном — расстояние до воды: улицы идут вдоль берега;
  - на склоне — высота: улицы по горизонталям.
  Первая улица (набережная или главная) берётся только у своей кромки воды, а не у берега за мысом. Если изолиний нет (посёлок внутри острова), главная улица кладётся по длинной оси границы.
- **Поперечные** — трасса по градиенту «высота + 0.25 · до воды». Где уклон больше 0.25 — лестница.
- **Площадь** 20×20, на склоне запасной вариант 16×16. **Резервы** общественных зданий ставятся у площади; пакгауз, таможня и лоцманская — у набережной.
- **Причалы**: у каждого типа своя длина и глубина у конца — мол 40 м / 2.5 м, пирс 22 м / 1.8 м, стенка 8 м / 1.2 м, мостки 10 м / 1.0 м.
- **Дороги** соединяют посёлки одного массива суши (связная суша, а не запись `islands`): дерево минимальной длины (MST) и путь A* между концами улиц.
- **Знаки МАМС-A**:
  - латеральные пары на входах в бухты; расстояние между буями ≤ 0.7 ширины бухты;
  - кардинальные вехи у групп камней, со стороны порта;
  - знак отдельной опасности над подводными камнями.
  Модели всех видов — в `makeBuoy(def.kind)`. В игре и на стенде буи берутся из `world.buoys` (ручные + знаки плана).

## Шаг 3б. Постройки по плану (только демо)
- **Строитель** `settlements.js` теперь только ставит объекты по `plan` (`buildSettlements(hf, bio, map, plan)`):
  - ленты всех улиц плана (`road-cobble` / `road-dirt` / `path`, лестницы — `stairs-slope`) и дорог `plan.roads`
    (с кусками `segs`); короткие куски от 5 м больше не выбрасываются;
  - подпорные стенки `retaining-wall`: где земля сбоку улицы в границе посёлка ниже полотна (или выше) больше чем на 1.2 м,
    высота — по перепаду, 1–4 м;
  - площадь, фонтан и мелочь — по `plaza`; общественные здания — по `reserves` (у ратуши флагшток);
  - причалы — по `berths`; кран, грузы, мачта у мола; стапель, верфь, спасстанция или сходы к воде — на свободной кромке
    у набережной; у деревень лодочные сараи, лодки и сушилки при мостках;
  - дома вдоль проезжих улиц, тип — по зоне плана (`core` / `residential` / `waterfront` / `outskirts`); не встал —
    дом поменьше (в городе до городского дома, в деревне до хижины);
  - хутора — вдоль полевых дорог со стороны окраин и полей; мельницы — на клетках полей (нет полей — на окраинах).
- **Удалено** из строителя: сеточная раскладка `town()` / `village()`, оси `seaward`, своя прокладка дорог.
- **«Архипелаг»** не менялся: старый строитель заморожен в `settlements-v1.js`, выбор в `world.js` по `plan: 'v2'`.
  Сверка: 1069 построек, 2.6 км, 0.66 млн треугольников — как в `archipelago-map/summary.md`.
