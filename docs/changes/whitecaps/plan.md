# Барашки на гребнях волн — план

Выделено из эксперимента с водой (`docs/changes/flat-water`, шаг 21), ветка `flat_water`.

## Задача
Пена-барашки на гребнях при усилении ветра:
- лежат вдоль гребня; при умеренном ветре их немного и они мелкие, с ветром их больше и они крупнее;
- рисуются цветами кильватера; наветренный край — «сильная пена»;
- за барашком шлейф по подветренному склону, шире с ветром;
- живут 10–15 с: растут, ненадолго держатся, гаснут.

## Шаги
1. Поле волн по пикселю (`WAVE_FIELD_GLSL`): высота `waveHn`, фаза и доля главной волны. Готово, `a216ef3` (WIP).
2. Полосы вдоль гребня, общая палитра пены, рябь выключена. Готово, `a216ef3` (WIP).
3. Шлейф: сначала по наветренному склону, потом перенесён на подветренный. Шум прибоя вблизи, рисунок едет с гребнем и меняется медленно. Готово, не закоммичено.
4. Цикл жизни, отдельный от высоты гребня: от одной высоты барашек жил 3–5 с. Готово, не закоммичено.
5. Сегменты разной длины с зазорами, случайный сдвиг от гребня, группы, мельче при слабом ветре. Готово, не закоммичено.
6. Производительность: цена 5–7 % основного прохода, кнопка «Замер GPU», ранние выходы в шейдере. Готово, не закоммичено.
7. Дальше по решению пользователя:
   - брызги с гребней по циклу жизни барашков;
   - барашки на зыби;
   - не рисовать барашки на дальнем кольце, если нужно ускорить.

Подробности и состояние — в `summary.md`.
