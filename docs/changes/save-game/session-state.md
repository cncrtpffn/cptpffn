# Сохранение игры — состояние сессии (2026-11-26)

Ветка `save-game` (от `tutorial-quests`). **Всё сделано и проверено, не закоммичено, ждёт ОК на коммит.**
План — `plan.md`, что сделано и проверки — `summary.md`.

## Где остановились
- Сохранение мира между сессиями, скачивание файла, загрузка из файла и удаление прогресса работают (подробно — `summary.md`).
- Решения пользователя:
  - в файл идут мир, прогресс обучения и флаг авто-матроса;
  - «Удалить прогресс» стирает мир и обучение, настройки (авто-матрос, свёрнутость панелей) остаются;
  - после загрузки файла и после удаления страница перезагружается.
- Отличие от плана: сохранение выключено не только с `?nosave`, но и с `?pos` и `?t`.

## Как проверяется файл при загрузке (`importBundle`, `src/save.js`)
«Чужой» — значит не наш формат. Подписи и привязки к игроку нет. По порядку:
1. Не JSON — отказ: «Файл не похож на сохранение».
2. Нет `kind: "catboat-save"` — отказ с тем же текстом (любой другой JSON).
3. `v` не равно 1 — отказ (`error: 'version'`). Тост тот же, отдельного про версию нет.
4. `world` есть, но без `map` или без числовых `boat.x` / `boat.z` — отказ (`error: 'broken'`).
   Остальные битые поля отбрасываются, на их место встают значения из `start.json` (`cleanWorld`).
5. `quests` проверяется только на форму (объект `done`). Неизвестные id квестов и записи без `best`
   отбрасывает `createProgress` при загрузке.

Все проверки идут до записи: при отказе хранилище не меняется.

Не ловится (сознательно, одиночная игра без сервера):
- сохранение другого игрока или исправленное руками (можно вписать себе пройденные уроки);
- файл другой карты — принимается, игра переходит на эту карту;
- координаты вне мира или на суше — лодка встанет туда, с мели снимает «Вывести на глубину».

## Возможные доработки (предложены, пользователь не решил)
- Проверять, что координаты лодки лежат в границах карты.
- Отдельный тост «Сохранение из другой версии игры» для `error: 'version'`.
- Известные ограничения (из `summary.md`):
  - скорость лодки не сохраняется;
  - время суток берётся из панели погоды (`?tod` в сохранение не попадает);
  - сворачивание вкладки (`document.hidden`) автотестом не проверено.

## Как продолжить
- Тесты модуля: `/System/Library/Frameworks/JavaScriptCore.framework/Versions/Current/Helpers/jsc -m src/debug/run-save.mjs` (32 проверки).
- В браузере: `python3 -m http.server 8080` из корня, состояние — `localStorage['catboat.save.demo']`, объект `window.__sim`.
- После ОК — коммит на `save-game`: `src/save.js`, `src/debug/run-save.mjs`, `src/main.js`, `src/ui/weather-panel.js`,
  `src/params.js`, `index.html`, `style.css`, `docs/changes/save-game/`.
