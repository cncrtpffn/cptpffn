## Соглашения кода библиотеки
- **Запись реестра:** `{ name, category, styles?: true, footprint: { w, d }, water?: true, params?: { key: { min, max, step, value, label } }, variants?: n, build }`.
- **`build(b, base, opts, rng)`** пишет в `PropBatch`. `opts = { style, variant, ...params }`. Может вернуть `{ extras }` — светящиеся меши через `glow(base, …)`, уже в СК батча (`base` применена).
- **СК объекта:** фасад к +Z, начало на земле в центре футпринта.
- **Объекты у воды:** начало на кромке, вода в +Z, уровень воды y=0, дно до −3.2 м (`SEABED`).
- **Стиль** — палитра `palette(style)`; цвета берутся через `pick(p.wall, rng)` и т. п.
- **Вид:** low-poly, flat shading, цвет по вершинам. Окна и двери — вставки на грани через `faceFrame(base, '+z', halfDepth)`, затем `windowAt` / `windowRow` / `doorAt`.
- **Крыши:**
  - `gable` — конёк вдоль X; для конька вдоль Z передать `ry: Math.PI / 2` и поменять местами `w`/`d`;
  - `hip` — вальмовая.
- **Бюджет треугольников:** малые объекты до 300, дома 400–1500, крупные (церковь, пакгауз) до 2500.
- **Стиль кода:** как в файлах вокруг — короткие русские комментарии, плотный код.

## Как проверять
- **Сервер проекта** уже крутится на `http://127.0.0.1:8080` (запущен пользователем). Если нет — `python3 -m http.server 8080 --bind 127.0.0.1` в фоне вне песочницы.
- **Стенд:**
  - объект: `/src/debug/props-viewer.html?obj=<id>&style=<s>&variant=<n>&views=turn` (4 ракурса);
  - библиотека: `?cat=housing&style=all`.
- **Chrome DevTools MCP** (`mcp__chrome-devtools__*`), страница обычно `pageId 10`:
  - после правок открывать `navigate_page` с `ignoreCache: true` — иначе браузер отдаёт старые ES-модули (на этом уже обожглись);
  - консоль — `list_console_messages` с `types: ["error","warn"]`.
- **Скриншоты дорогие по контексту** (именно они съели прошлую сессию):
  - снимать в маленьком окне: `resize_page` 1200×678 или меньше;
  - на объект — один кадр `views=turn`, без повторов;
  - в доку сохранять через `filePath` в `docs/changes/structures-library/img/`; путь scratchpad MCP не принимает;
  - не перечитывать сохранённые файлы без нужды.
- **Треугольники по всем объектам** — `evaluate_script` с `await import('/src/scene/structures/index.js')` и подсчётом `position.count / 3` по мешам `createStructure(id, { style }, seeded(1))` (пример в истории этапа 3).
- **Игра:** `/index.html` должна грузиться без ошибок — `island.js` импортирует реестр.
