# 12 · Интерактивное обучение — шаг 0+1: ассистент с переключателем и «телеграфом»

## Контекст
Эпик `docs/backlog/12-interactive-tutorial.md`. Новичку нужен режим «только руль»: ассистент ведёт шкот,
шверт, рифы и пересаживает рулевого. Ответы пользователя: матроса пока нет; рулевой пересаживается сам, но
только на банки (±1, на комингс/откренку не вылезает); ассистент «гонщик», точный; по умолчанию выключен,
выбор помнится; скорость — «телеграф» стоп / средний / полный вместо шкота. Сейчас: переключатель в HUD
справа под кнопкой паузы; в режиме ассистента контролы рифов, экипажа и шверта скрыты, шкот заменён телеграфом.

## Что делаем

### 1. `src/physics/assist.js` (новый, без three/DOM — тестируется в jsc)
`createAssist(cfg = BOAT)` → `{ telegraph: 0|1|2, hint, request(delta), controls(dt, boat, wind, rudder) }`.
Состояние: сглаженные TWS и крен (EMA), таймеры гистерезиса рифов, таймер подсказки.
`controls(...)` вызывается на каждом шаге физики (внутри цикла STEP) и возвращает
`{ rudder, sheet, board, crewPos }` — **оси**, а не прямые значения: шкот и шверт ходят со своими
скоростями (`sheetRate`, `boardRate`), HUD и гик показывают реальное движение. Рифы — `boat.sail.reef(±1)`
(анимация `reefTime` уже есть).
- **Шкот:** цель `|awa| − α`, α по телеграфу: полный 24° (как в текущем автопилоте), средний ≈10°
  (CL вдвое меньше), стоп — шкот потравлен до `sheetMax`. Поправка на крен: при `|φ|` выше порога
  (≈20°) цель травится пропорционально; «паника» (`|φ|` > ≈35° или вода в кокпите) — шкот до упора.
  Ось = P-регулятор `(sail.sheet − цель)/зона`, clamp ±1.
- **Телеграф:** `request(−1)` на полном курсе (|awa| > `sheetMax` − запас: парус тянет при любом шкоте)
  блокируется, `hint = 'Развернитесь к ветру, чтобы уменьшить скорость'` на ~3 с. Та же подсказка, пока
  режим стоп/средний не достижим (увалились после снижения).
- **Экипаж:** наветренная банка `±1` по знаку `aw.twa`, с гистерезисом у чистого фордевинда (|twa| > ~170° —
  не пересаживаться). Откренку (±2) не использует.
- **Шверт:** опущен при |twa| < ~110°, на фордевинде ~0.3; `boardAground` — поднять.
- **Рифы:** по сглаженному TWS и среднему крену/травлению шкота с гистерезисом и задержкой (≈5 с);
  стартовые пороги ~9 / ~12 м/с, калибруем прогонами (п. 5). Парус (ступень 3) не спускает.

### 2. Интеграция в `src/main.js`
- `const assist = createAssist()`; `assistOn` из `?assist=0|1`, иначе `localStorage['assist']`
  (try/catch), по умолчанию выкл.
- В цикле шага: `const c = assistOn ? assist.controls(STEP, boat, wind, controls.rudder) : controls`.
- Пока включён: события `reef`/`crew` игнорируются; `↑/↓` (и тач-слайдер шкота) не шкот, а телеграф —
  по фронту нажатия `assist.request(±1)` (держать ↑ = один шаг, не повтор). Ось шкота из `input.controls`
  в физику не идёт.
- Отладочный `autopilotControls()` (`?auto`, `?t`): руль — свой курсодержатель, остальное — через
  `assist.controls` (заменяет «шкот |awa|−24°, откренка» — первый автопилот уходит).
- Горячая клавиша переключателя — `T` (в `input.js` событие `'assist'`), строка в справке.

### 3. UI
- `index.html`: в `#side-btns` после `#btn-pause` — `<button id="btn-assist" class="ui-btn soft toggle">`
  с иконкой (новая `assist` в `src/ui/icons.js`, по образцу board/reef/crew), `aria-pressed`, title
  «Авто-матрос (T)». Включённое состояние — как `.ui-btn.on` (тёмный фон).
- В `#hud-controls` новая строка «Телеграф ↑↓» с чипами `стоп / средний / полный` (по образцу рифов);
  `body.assist` в CSS: скрывает строки шкота, шверта, экипажа, рифов и тач-кнопки `.t-btns`, показывает
  телеграф; на таче метка слайдера «шкот» → «ход», индикатор слайдера — уровень телеграфа.
- `hud.update({ …, assist })`: чипы телеграфа; `assist.hint` перекрывает текст `#sail-status`;
  в режиме стоп вместо «Парус полощет — выберите шкот» — «Стоп: шкот потравлен».
- Справка (`#help`): строка про `T` / кнопку и про телеграф (клавиатура и тач).
- `src/params.js`: `{ name: 'assist', kind: 'num', group: 'Ветер и лодка', values: '0 | 1', … }`
  (таблица на `tools.html` строится из реестра сама).

### 4. `src/debug/polar.js`
`runCase({ assist: true, telegraph })` — каналы кроме руля через `assist.controls`; ручной режим
(`alpha`, `sheet`, `hike`, `board`) остаётся для опытов с физикой. Новый `src/debug/run-assist.mjs`
(jsc): поляры ассистента против ручной настройки 4/7/10/13/16 м/с и сценарий порывов 6 → 14 м/с.

### 5. Проверка
- `jsc -m src/debug/run-assist.mjs`: скорость на полном ходу не хуже ручной (`run-polar`, откренка на банке)
  больше чем на ~5 %; без переворота до 16 м/с и в порывах 6→14; стоп на бейдевинде — скорость → ~0,
  средний — заметно ниже полного. По результатам — пороги рифов/крена.
- В игре (python http.server вне песочницы, headless Chrome/DevTools MCP): кнопка под паузой,
  вкл/выкл, перезагрузка помнит выбор, `?assist=1`; скрытие контролов и телеграф на десктопе и `?touch=1`;
  подсказка при попытке сбавить ход на фордевинде; круг по демо одним рулём. Скриншоты в `img/`.
