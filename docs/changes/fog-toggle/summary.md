# Галка «Туман» — итог

Сделано, не закоммичено.

- `src/scene/environment.js` — туман хранится в `env.fog`; `env.fogEnabled` (get/set) ставит его на сцену или снимает.
  Цвет и дальность обновляются и при выключенном тумане, при включении он сразу верный для времени суток и облачности.
- `src/main.js` — деградация неба: фон из `env.fog.color` вместо `scene.fog.color`.
- `src/ui/weather-panel.js` — галка «Туман» в папке «Сцена».

При переключении three.js перекомпилирует материалы с туманом — короткий фриз.

## Что видно без тумана
Дальний план чёткий, острова в полном цвете. Линия горизонта (край кольца воды на 3000 м) — резкая
светлая полоса у неба, но не режет глаз. Стык детальной сетки воды с кольцом на спокойной воде не заметен.

## Проверка
Chrome DevTools: галка есть в панели; выкл → `scene.fog === null`; при выключенном сменить облачность
на «Пасмурно» и время суток → вкл: near/far пасмурные, цвет по времени суток. Ошибок в консоли нет.
Скриншоты с туманом и без сравнены.
