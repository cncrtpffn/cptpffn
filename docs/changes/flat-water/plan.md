# Плоская вода

Эксперимент с отрисовкой воды: отключить текстуры, шейдерные эффекты и отражения, залить воду одним цветом.

- Режим «плоская заливка» с переключателем и выбором цвета в панели (папка «Вода»), по умолчанию включён.
- Ближняя вода: `MeshBasicMaterial` (без освещения), в вершинах остаётся только смещение волн Герстнера — чтобы лодка не качалась сквозь неподвижную плоскость.
- Дальняя вода: `MeshBasicMaterial` того же цвета, без инъекций.
- Planar-отражение (второй рендер сцены) в этом режиме не выполняется.
- Обычная вода остаётся и включается снятием галочки.
