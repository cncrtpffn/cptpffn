# Эксперимент с водой (flat-water)

## Цель
Поиграть с отрисовкой воды: начать с нуля, убрать текстуры, шейдерные эффекты и отражения, залить воду одним цветом и дальше добавлять только то, что действительно нужно.

## Правила эксперимента
- Совместимость со старой водой не нужна: старый код удаляем, а не прячем за переключатели (история есть в git: `main`, коммит `2b56165`).
- Доку на промежуточных шагах не ведём — правки часто противоречат друг другу. Пишем итог, когда результат понятен, или когда эксперимент ставится на паузу (как сейчас).

## Шаги, пройденные на данный момент
1. Одноцветная заливка без освещения (`MeshBasicMaterial`), волны Герстнера в вершинах оставлены.
2. Освещение (`MeshStandardMaterial`, аналитические нормали волн).
3. Удалён весь старый код воды, отражений и кильватера.
4. Без бликов: `MeshLambertMaterial`.
5. Своя мягкая тень на воде, гаснущая с расстоянием от предмета (ветка `soft-shadow-boat`, влита в `flat_water`).
6. Ручные волны в панели: высота, направление, длина двух систем, мгновенно; свёрнутость вкладок панели запоминается.
7. Нормаль по пикселю вместо интерполяции по вершинам — гладкий свет без новых полигонов.
8. Галка «Сетка волн» (wireframe).
9. Геометрия: сетка гуще у лодки, короткие волны убраны из геометрии (остались в свете), ползунок «Острота гребней».
10. Спектр из 8 компонент с разбросом вместо 4 фиксированных — убран регулярный узор «шишек» на гребнях.
11. Гладкость волн: амплитуда ∝ длина^p (ползунок, по умолчанию 2.8) — убрано пятнистое «ступенчатое» затенение.
12. Волны вдали: дальнее кольцо освещается той же нормалью волн по пикселю — волны видны до горизонта без геометрии.
13. Крышка кокпита — вода не видна сквозь пол лодки.
14. Прибой возвращён: пена у кромки, буруны и мелководье из `main` в новой Lambert-воде, панель «Прибой».
15. Физика лодки под новые волны: плоскость воды под корпусом по 7 точкам, качка и дифферент с упреждением по скорости воды — корпус идёт по видимой волне.

Подробности, текущее состояние и как продолжить — в `summary.md`.
