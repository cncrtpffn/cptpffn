# Плоская вода — итог

## Что изменилось
- `src/scene/water.js`: код смещения Герстнера вынесен в константы `WAVE_DISP_GLSL` / `WAVE_NORMAL_GLSL` / `WAVE_TRANSFORM_GLSL` (общие для обоих материалов). Добавлены `flatMat` (MeshBasicMaterial + только смещение вершин) и `flatFarMat`, объект настроек `water.flat = { enabled: true, color: '#2f86b5' }`. Материал меняется в `update()` по `flat.enabled`.
- `src/main.js`: planar-отражение не рендерится при `water.flat.enabled`.
- `src/ui/weather-panel.js`: папка «Вода» с полями «Плоская заливка» и «Цвет».

## Что осталось
- Туман сцены действует на плоскую воду (горизонт растворяется), это не эффект воды.
- Тени на плоской воде не видны: MeshBasicMaterial их не принимает.
- Пена, кильватер, прибой, мелководье, рябь и блики в этом режиме не рисуются; настройки «Отражения» и «Прибой» тогда ни на что не влияют.

## Проверка
Chrome DevTools: в плоском режиме вода одного цвета, лодка и острова на месте, ошибок в консоли нет; при снятой галочке возвращается обычная вода (MeshStandardMaterial).
Headless Chrome со swiftshader для этой сцены не подходит: даже исходная версия там рендерится чёрным экраном.

## Шаг 2: освещение
- `flatMat` и `flatFarMat` теперь `MeshStandardMaterial` (roughness 0.38, metalness 0.02 — как у обычной воды) вместо `MeshBasicMaterial`.
- Ближняя вода получает аналитические нормали Герстнера (`WAVE_NORMAL_GLSL` в `beginnormal_vertex`): волны видны по затенению. Дальняя — плоская нормаль вверх; на стыке волны уже гаснут (`edge` → 0), шва нет.
- Вода принимает тени (видна тень лодки и паруса).
- В панель добавлен слайдер «Шероховатость» (`water.flat.roughness`, общий для ближней и дальней воды).
- Проверено в Chrome DevTools: ошибок в консоли нет.
- Пункт «тени не видны» из ограничений шага 1 больше не актуален.

## Шаг 3: удалён старый код воды
Пользователь: это эксперимент, совместимость со старой водой не нужна.
- `src/scene/water.js` переписан: только освещённый `MeshStandardMaterial` одного цвета + вершины Герстнера с нормалями; дальнее кольцо — тот же материал без волн. API: `createWater(waves, { size, segments, shoreMap })`, `water.update(waves, x, z)`, `water.settings = { color, roughness }`.
- Удалены `src/scene/wake.js` (след нужен был только шейдеру воды) и `src/scene/planar-reflection.js` (вместе с `markReflected` в main.js и пометками `userData.reflect` / `noReflect` в boat-rigging.js и island.js).
- `src/scene/water-fx.js`: остались только `NOISE_GLSL` (небо, облака) и `SHORE_DAMP_GLSL`.
- Убраны `sunGlint` (environment.js) и `light.glint` (sky.js) — использовались только бликами воды.
- Панель: папка «Вода» = «Цвет» + «Шероховатость»; папки «Отражения» и «Прибой» удалены, галочки «Плоская заливка» больше нет.
- Брызги (нос, прибой, гребни) не трогались — они от воды не зависят.
- Проверено в Chrome DevTools: сцена рендерится, ошибок в консоли нет.

## Шаг 4: без бликов
- Ближняя и дальняя вода — `MeshLambertMaterial` (только рассеянный свет) вместо `MeshStandardMaterial`. Просили шероховатость 1, но у Standard и при roughness 1 остаётся френелевский блеск под скользящими углами; у Lambert зеркальной составляющей нет вовсе.
- Слайдер «Шероховатость» и `settings.roughness` удалены; в панели «Вода» остался только цвет.
- Проверено в Chrome DevTools: бликов нет, волны видны по затенению, тени на месте, ошибок нет.
