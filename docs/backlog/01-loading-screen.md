# Экран загрузки с описанием этапов

**Из todo.md:** экран загрузки с описанием того, что сейчас происходит. Нужен и для отладки, и для красоты.

## Цель
Пока игра стартует, показывать текущий этап («строим рельеф…», «запекаем карту берега…», «компилируем
шейдеры…») с прогрессом. В режиме отладки показывать ещё и время каждого этапа. Убрать фриз после
исчезновения заставки.

## Что есть сейчас
- Статичный `<div id="loading">Загрузка…</div>` (`index.html:130`, стиль `style.css:87`). Удаляется прямо
  перед первым кадром (`src/main.js:265`).
- Старт в `main.js`: единственный реально асинхронный шаг — `await fetch('start.json')` (`:31`). Всё
  остальное, от рендерера (`:42`) до `requestAnimationFrame` (`:266`), идёт одним синхронным блоком.
  Браузер не перерисовывает DOM, пока этот блок не закончится, поэтому любой текст этапа сейчас не
  будет виден.
- Тяжёлые этапы:
  - `buildWorld` (`main.js:71`), внутри: поле высот → биомы → план поселений → рельеф → поселения →
    растительность. Каждый этап уже меряется через `lap()` (`src/scene/terrain/world.js:21-30`), сводка
    уходит в консоль (`world.summary()`).
  - `bakeShoreMap` (`main.js:77-80`): 4096² на десктопе, 2048² на таче.
  - `createEnvironment`, `createWater`, модель лодки, частицы (`main.js:72-96`).
  - необязательная промотка `?t=` (`main.js:191-204`).
- Шейдеры компилируются лениво, в первом `renderer.render()` и `planar.render()`. Это происходит уже
  после удаления заставки, поэтому игрок видит замёрзший первый кадр (комментарий в `main.js:214`
  об этом прямо говорит).
- До запуска `main.js` браузер грузит модули с CDN (three, addons — `index.html:18-25`), и на это наш
  код никак не влияет.

## Черновой план
1. Модуль `src/ui/loading.js`:
   - `loading.step(label, weight)` — показать этап, закрыть предыдущий и записать его длительность;
   - `await loading.yield()` — отдать кадр браузеру (`requestAnimationFrame` + `setTimeout 0`), чтобы
     текст и полоса успели отрисоваться;
   - прогресс-бар по весам этапов (веса — по типичным таймингам из `world.summary()`);
   - `loading.done()` — плавно скрыть заставку и записать сводку таймингов в консоль.
2. `main.js`: разбить стартовый блок на этапы с `await loading.yield()` между ними. Top-level await
   уже используется, так что переписывать структуру не придётся.
3. `buildWorld(map, { onStep })` — необязательный колбэк, вызывается в каждом `lap()`. Стенд карты
   (`src/debug/map-viewer.html`) продолжит работать без него. Чтобы этапы внутри `buildWorld` были
   видны, сама функция должна стать асинхронной (`buildWorldAsync`) или отдавать кадр через колбэк.
   Вариант: оставить синхронную `buildWorld` для стенда и добавить рядом асинхронную обёртку с тем же
   порядком шагов.
4. Этап «компиляция шейдеров»: `await renderer.compileAsync(scene, camera)`, затем один прогревочный
   `planar.render` и `renderer.render` под заставкой. Только после этого — `loading.done()`.
5. Отладка: `?log` выводит таблицу этапов с мс в консоль, `?loading=keep` оставляет экран с
   таймингами до клика.
6. Оформление: название, полоса, текущий этап, под ним мелким шрифтом список завершённых этапов.
   Цвета — из `style.css` (`--ink`, фон как сейчас `#9fd3ec`).

## Риски и ограничения
- Каждый `yield` добавляет ~1 кадр (16 мс) к старту. При 10–12 этапах это несущественно.
- `compileAsync` требует расширения `KHR_parallel_shader_compile`. Где его нет, three.js компилирует
  синхронно, и это просто будет видно как отдельный этап.
- Прогресс загрузки модулей с CDN из `main.js` не увидеть: к моменту его запуска они уже загружены.

## Вопросы к пользователю
1. **Стиль.** Минимальный (текст этапа и полоса) или оформленный экран (арт или силуэт лодки, советы по
   управлению)? *По умолчанию: минимальный, с аккуратной типографикой и подсказкой по управлению.*
2. **Тайминги этапов** показывать всем или только с `?log`/`?debug`? *По умолчанию: всем мелким серым
   шрифтом.* Это дёшево и полезно для отладки на телефоне.
3. **Кнопка «Начать».** Держать экран до клика после загрузки? Это нужно, чтобы браузер разрешил звук
   (см. [07-sounds.md](07-sounds.md)), и даёт время прочитать подсказки. *По умолчанию: да, если звук
   будет; до тех пор — автоскрытие.*
4. **Модули с CDN.** Показывать этап «загрузка модулей» до старта `main.js`? Для этого нужен маленький
   инлайн-скрипт в `index.html`. *По умолчанию: нет, хватит статичного текста «Загрузка модулей…»
   в разметке.*

## Как проверить
- Десктоп и `?touch=1`: этапы меняются, полоса растёт, после скрытия нет фриза (`?perf=1` — первые кадры
  без пика CPU).
- Сумма таймингов совпадает с `world.summary()` и `bakeMs`.
- Стенд карты открывается как раньше.
