# Раздельные конфиги для телефона и десктопа

**Из todo.md:** добавить раздельные файлы конфига для телефона и десктопа, вынести в них все
расходящиеся параметры, чтобы избежать условий и проверок на тач внутри модулей.

## Цель
Всё, что отличается на телефоне и десктопе, лежит в двух файлах профилей. Модули читают значения из
выбранного профиля и сами `isTouchDevice()` не вызывают.

## Черновой план
1. **Профили** `src/platform/desktop.js` и `src/platform/phone.js` — объекты одной формы:
   - `render { shadowType, shadowSize, shadowRange, shoreMapMax, planarReflection, particleScale,
     dprMax, waterSegments? }`;
   - `ui { touchControls, controlsCollapsed, hintCollapsed, weatherDialog, topBar, lockPortrait,
     haltInLandscape }`.
2. **Выбор** — `src/platform/index.js`: один раз определяет профиль (логика из `isTouchDevice`) и
   экспортирует `PLATFORM`. URL-параметр `?platform=phone|desktop` (в реестр `params.js`; `?touch=1`
   остаётся алиасом). Класс `body.touch` ставится отсюда же — CSS не меняется.
3. **Замена проверок** в `main.js`, `weather-panel.js`, `touch.js` на `PLATFORM.*`. `isTouchDevice()`
   остаётся только внутри `platform/index.js`.
4. **Тест в jsc:** у обоих профилей одинаковый набор ключей (защита от рассинхрона).
5. README (разделы «Структура», «На телефоне») и таблица на `tools.html` (из реестра).

Новые `src/platform/{index,desktop,phone}.js`, `src/main.js`, `src/ui/touch.js`,

## Риски и ограничения
- Чистый рефакторинг: картинка и производительность не должны измениться ни на одном профиле.
- Планшеты попадают в профиль телефона (как и сейчас).
- Media-query раскладки (ширина экрана) и профиль устройства — разные оси, смешивать их не стоит.

## Вопросы к пользователю
1. **Сколько профилей:** два (телефон/десктоп) или три (+ планшет: тач, но мощнее и экран больше)? *По
   умолчанию: два, структура допускает третий.*
2. **Выбор профиля** — по тачу (как сейчас) или по тачу + размеру экрана? *По умолчанию: как сейчас.*
3. **Формат:** JS-модули или JSON (как `start.json`)? *По умолчанию: JS — с комментариями,
   импортируются в jsc.*
4. Выносить ли в профиль раскладку CSS (переменные размеров HUD) или CSS остаётся на `body.touch` и
   media-query? *По умолчанию: CSS не трогаем.*
5. Нужен ли игроку переключатель качества графики (низкое/высокое) поверх профиля? *По умолчанию: нет,
   отдельная задача.*
6. Переводить ли стенды (`src/debug/*-viewer.html`) на профили? *По умолчанию: нет, у них своя логика.*

## Как проверить
- A/B скриншоты main против ветки: десктоп и `?touch=1` / `?platform=phone` — идентичны.
- `grep isTouchDevice` находит только `src/platform/`.
- `?perf=1` на обоих профилях без изменений.
- Сводка Архипелага на стенде карты не изменилась (общий код).
